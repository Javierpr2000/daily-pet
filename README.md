# daily-pet

Desktop to-do with a walking pet companion. Daily recurring tasks, today-only tasks, multiple ticks per day.

```
npm install
npm start
```

Left-click pet: toggle task panel. Drag: move it. Right-click: walk on/off, size, quit.
